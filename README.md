# 🐍 Python Scripting & Automation Projects

Welcome to my collection of practical Python scripts that demonstrate how to automate common tasks using built-in modules like `os`, `shutil`, `subprocess`, `csv`, `json`, and `logging`.

Each folder contains a set of focused examples to help you understand and reuse automation techniques in real-world scenarios.

---

## 🔧 Modules

### 1. [`file_folder_management`](./file_folder_management)
Scripts to automate file and folder tasks:
- Create, delete, move, and rename files/folders
- List contents and check file properties

### 2. [`file_formats`](./file_formats)
Working with common file formats:
- CSV read/write
- JSON save/load
- Text file processing

### 3. [`system_commands`](./system_commands)
Use the `subprocess` module to:
- Run OS-level commands like `ls` or `dir`
- Capture command outputs and handle errors

### 4. [`logging_and_errors`](./logging_and_errors)
Error handling and logging:
- Basic logging setup
- Rotating log files
- Logging exceptions from try-except blocks

### 5. [`automation_projects`](./automation_projects)
Mini real-world projects that combine concepts:
- Automatically back up folders
- Clean up old `.log` files
